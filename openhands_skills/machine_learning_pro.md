\# Machine Learning Best Practices



\- Πάντα χρησιμοποίησε seeds για reproducibility

\- Κάνε feature engineering με RSI, MACD deltas, volume ratios

\- Χρησιμοποίησε walk-forward optimization για backtesting

\- Απόφυγε data leakage

\- Αξιολόγησε με out-of-sample testing

\- Σκέψου reinforcement learning για portfolio allocation
